# 🌸 Kazumi Changelog

All notable changes, expansions, and feature milestones.

---

## [2.0.0] - 2026-09-30

### Added
- **Full Moderation Suite**: `/warn`, `/warnings`, `/clearwarnings`, `/timeout`, `/kick`, `/ban`, `/unban`, `/clear`, `/slowmode`, `/lock`, `/unlock`, `/automod`.
- **AutoMod Engine**: Real-time message flood, duplicate spam, mass mention, invite link, arbitrary link, and prohibited language detection.
- **Server Audit Logging**: `/logging` with detailed audit embeds for member joins, leaves, edits, deletions, bans, unbans, and role updates.
- **Community Automation**:
  - Customizable welcome and goodbye card templates (`/welcome`, `/goodbye`).
  - Automated role assignment on member join (`/autorole`).
  - Interactive button-role panels (`/reactionrole`).
  - Support ticket system with private channels and transcripts (`/ticket`).
  - Persistent giveaway system with button entries (`/giveaway`).
  - Custom command manager and tag dispatcher (`/customcommand`, `/tag`).
- **Server Info & Utilities**: `/serverinfo`, `/userinfo`, `/avatar`, `/roleinfo`, `/channelinfo`, `/permissions`, `/ping`, `/uptime`, `/botinfo`, `/poll`, `/announce`, `/remind`, `/time`.
- **Voice & Music**: `/play`, `/pause`, `/resume`, `/skip`, `/queue`, `/nowplaying`, `/volume`, `/loop`, `/stop` with interactive UI buttons.
- **Cognitive & Social Intelligence**:
  - Mood System (8 emotional states).
  - Social Memory Graph & Server Memory.
  - Conversation Continuity tracking across breaks.
  - Smart Silence Engine to prevent AI spam.
  - Natural reaction predictor.
  - Periodic Kazumi Moments and community questions.
- **Web Dashboard REST API**: Telemetry endpoints for overview, moderation, tickets, giveaways, and settings.
- **Documentation Suite**: Architecture, feature catalog, deployment, commands, setup, configuration, database, troubleshooting, and changelog.

### Preserved
- Unchanged affection, warmth, diary, and personality system.
- Complete creator lore recognizing Aamir the Chad and Sir Shan D. First.
- All 16 original slash commands.
